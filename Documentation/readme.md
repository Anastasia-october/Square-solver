# Square-solver
Решай квадратные уравнения с помощью этого консольного приложения!

# Функционал
## Решение квадратного уравнения
Данное приложение принимает коэффициенты квадратного уравнения, выводит количество корней и сами корни
Есть возможность выбора цвета и шрифта выводимых данных.
Если уравнение имеет вид `bx + c = 0` стоит ввести первый коэффициент 0.
Программа выведет текстовые надписи в случае отсутствия корней или бесконечного количества корней.
## Построение графика
Вне зависимости от наличия корней программа строит график функции `y = f(x)` и печатает его в консоли. Точка пересечения осей всегда находится в центре консоли. Если график функции оказался за границами консоли будет выведено соответствующее сообщение.
## Тестирование
По окончанию решения уравнений программа автоматически запускает тестирование. Существуют два варианта тестирования
- С использованием написанных вручную тестов
- С использованием сгенерированных тестов
Генерируемые тесты меняются каждый запуск, написанные вручную тесты лежат в файле _references.txt_. Вы можете изменять их.
