Detailed Description

Release testing. Is called by main.

Launches manual or randomly generated tests. The choice of mode depends on the command-line argument. Function run_all_tests() is called by main() from main.cpp. Calls enum roots_flags solve_equation() form main.cpp to get roots. Other functions are called from function run_all_tests() or from functions called by it.
